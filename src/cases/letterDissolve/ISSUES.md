# Letter Dissolve 问题记录

## 记录规范
每次出现已犯问题时，按以下结构补充，避免重复踩坑：
- 问题描述
- 出现原因
- 影响范围
- 解决方案
- 后续注意点

---

## 2026-05-14 · 输入高频重绘导致纹理更新抖动

- 问题描述：表单每次键入都直接重绘整张 Canvas 信纸时，快速输入会出现纹理更新频率过高、渲染压力抖动。
- 出现原因：信纸底图 + 文本合成都在主线程执行，连续输入时会触发高频 `CanvasTexture.needsUpdate`。
- 影响范围：案例3 文本输入体验与帧率稳定性，尤其在高分辨率屏幕上更明显。
- 解决方案：对输入到纹理重绘加入 80ms 轻量节流（timer debounce），保证“实时更新”体验同时降低频繁刷新。
- 后续注意点：若后续增大纹理分辨率或增加更多视觉层，优先考虑“底图缓存 + 文本层单独绘制”并保持节流策略。

## 2026-05-14 · 控制面板遮挡全屏操作与空间

- 问题描述：右侧控制面板默认占据接近整屏高度，视觉上会遮挡/压住右下角全屏按钮使用体验，导致误判“没有全屏”。
- 出现原因：面板 `maxHeight` 过大且固定贴右侧，未预留全屏按钮操作空间，也缺少收起能力。
- 影响范围：案例3 交互可达性，尤其全屏切换、沉浸预览场景。
- 解决方案：新增“收起/展开”按钮；展开态限制面板高度，预留底部空间，收起后仅保留标题栏。
- 后续注意点：所有悬浮面板设计默认需预留右下角通用操作区，避免覆盖全屏、截图等全局按钮。

## 2026-05-14 · 文案中的字面量 \\n 未被识别为换行

- 问题描述：默认信件文案及用户输入若包含字面量 `\\n`，贴图渲染时未换行，导致文本排版异常。
- 出现原因：换行处理仅识别真实换行符 `\n`，未兼容转义文本输入。
- 影响范围：案例3 文本排版可读性，默认内容和复制粘贴场景都可能受影响。
- 解决方案：新增统一换行归一化，将 `\\r\\n` 与字面量 `\\n` 统一转换为 `\n` 再执行分段换行绘制。
- 后续注意点：凡是“文本转贴图”链路都应在排版前做换行归一化，避免输入来源差异导致渲染分叉。

## 2026-05-14 · 初始化进度为 0 仍出现顶部消散痕迹

- 问题描述：`uDissolveProgress = 0` 时，纸张顶部仍有轻微“燃烧/消散”视觉。
- 出现原因：消散边缘 `smoothstep` 过渡区在 `progress = 0` 时仍覆盖到 `vUv.y = 1.0` 顶部区域，导致 alpha 被部分压低。
- 影响范围：案例3 初始状态与重置状态视觉准确性，用户会误判“默认已烧蚀”。
- 解决方案：在 shader 中增加早返回分支，`progress <= 0.0001` 时直接输出原贴图，不执行消散计算。
- 后续注意点：所有消散 shader 都应明确约束 0/1 边界行为，避免过渡带在极值状态造成误差。

## 2026-05-14 · 新增破洞模式后粒子触发与纸面不同步

- 问题描述：仅扩展纸张 shader 为“整体破洞消散”时，粒子仍按竖向扫描逻辑触发，视觉上会出现纸面已消散但粒子未激活（或反之）。
- 出现原因：粒子顶点 shader 的触发条件依赖 `aUv.y`，是竖向模式专用逻辑，未跟随新模式切换。
- 影响范围：案例3 粒子与主体消散的一致性，影响特效可信度。
- 解决方案：粒子 shader 增加 `uMode/uNoiseScale/uNoiseSpeed`，在破洞模式改为按噪声阈值触发，与纸张同源规则同步。
- 后续注意点：新增消散模式时必须同时检查“主体片元逻辑 + 粒子触发逻辑 + 控件映射”三处是否一致。

## 2026-05-14 · 手动进度滑杆时粒子未联动显示

- 问题描述：拖动消散进度滑杆时，纸张进度变化明显，但粒子不出现或不跟随变化。
- 出现原因：粒子激活条件只依赖播放状态（`running/finished`），手动拖动时状态常为 `idle`，导致粒子被关闭。
- 影响范围：案例3“进度控制”交互完整性，用户会误认为粒子无法被进度控制。
- 解决方案：粒子激活条件加入“手动预览进度 > 0”判断，并区分自动完成与手动 1.0 预览，避免错误进入粒子淡出计时。
- 后续注意点：凡是提供手动进度控制的特效，主体与辅助特效（粒子/光带）都应支持同一进度预览。

## 2026-05-14 · 破洞消散阈值方向反转导致“越调越出现”

- 问题描述：破洞模式下拖动进度时，纸张不是消失而是逐渐出现，方向与预期相反。
- 出现原因：破洞阈值直接使用 `progress`，导致保留区域随进度增大而扩大。
- 影响范围：案例3 破洞模式主体消散逻辑与用户预期不一致。
- 解决方案：阈值改为 `1.0 - progress`，让进度增大时保留区域缩小；同时修正粒子触发公式，保持主体与粒子方向一致。
- 后续注意点：新增模式时需先用 `progress = 0/0.5/1` 三个点验证单调性，确保“进度方向”与语义一致。

## 2026-05-14 · 单层噪声导致消散边界观感生硬

- 问题描述：信纸消散边缘呈现明显块状/塑料感，视觉上不够自然，尤其在破洞模式下更明显。
- 出现原因：此前使用单层 value-noise，空间频率层次不足，缺少低频结构与高频细节的耦合。
- 影响范围：案例3 消散质感与整体观感，影响“纸张燃蚀/破洞”的可信度。
- 解决方案：改为分形噪声（FBM）+ 轻微域扭曲（domain warp）+ 细节层混合，保留现有控件参数语义（强度/尺度/速度）不变。
- 后续注意点：涉及材质质感时，优先使用“多频层 + 扭曲”噪声基线，避免回退到单层噪声方案。

## 2026-05-14 · 自动消散完成后粒子未真正关闭

- 问题描述：自动播放结束后，粒子看起来没有按预期消失，仍长期存在。
- 出现原因：状态同步把自动完成的淡出计时覆盖掉，并且粒子激活条件在完成态始终为 true。
- 影响范围：案例3 自动播放结束态视觉收尾与性能。
- 解决方案：保留自动完成的淡出计时；粒子激活条件加入“淡出结束后关闭”；手动预览进度与自动完成态分离处理。
- 后续注意点：涉及“自动播放 + 手动预览”共存时，必须拆分计时来源，避免状态同步误覆盖时序数据。
